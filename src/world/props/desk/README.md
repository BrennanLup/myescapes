# Desk terminal (workstream 5)

`DeskProps` mounts the "log a new escape room" desk at `ANCHORS.desk` (west wall).

- **Furniture:** honey-wood desk with a thick chamfered top, apron, modesty panel, slab leg with foot rail and a drawer cabinet (bevelled fronts, brass bar pulls), cables running down the back; a gaming office chair (teal + orange, pulled out and turned to the room) with a 5-star tapered base, twin-wheel casters, gas lift in a stepped shroud, tilt mechanism and lever, crowned seat with a waterfall edge and side bolsters, wrap-around backrest with lumbar curve, bolsters, head and lumbar pillows, and padded armrests; main monitor + angled side monitor ("crew chat") with slim bezels, chins, tapered back housings, VESA plates, necks and rounded feet; a keyboard with ~65 individual keycaps (orange Esc/Enter), sculpted mouse, desk mat, podcast mic (turned body, grille, shock mount) on a two-section boom arm with springs and a desk clamp, PC tower with fan hubs/blades behind the teal LED rings, a hollow mug with coffee, a ribbed cactus, sticky notes, and an articulated desk lamp (weighted base, two arms with springs and joints, thick conical shade with brass rim, cord) whose bulb sits exactly at `LAMPS.deskLamp` (derived via `deskWorldToLocal`, tested).
- **Terminal screen:** animated canvas texture (`terminal.ts`). `terminalFrame(t, hovered, roomCount)` is a pure function returning the lines, typed prompt (`> LOG A NEW ESCAPE ROOM`), cursor blink, button text and mic meter bars; `drawTerminal` paints it. The texture is only re-uploaded when the frame key changes (stepped at 8 fps). Used as map + emissive map with `toneMapped: false` so bloom picks it up.
- **Interaction:** the whole desk group is `interactable({ id: 'desk:terminal', kind: 'desk', event: record:open })`.
- **Hover glow:** when `hoveredId === 'desk:terminal'`, a damped 0..1 value boosts the screen emissive, brightens the LEDs and fades in an additive back-face teal rim around both monitors. The screen switches to `> READY TO RECORD`.
- **Colliders:** `desk:desk` and `desk:chair` (world AABBs from `deskColliders()`).
- **Draw calls:** static parts are built with the living set's `PartsBuilder` and geometry kit (`../living/builder.ts`, `../living/geo.ts`) and merged per (material, castShadow) bucket: 20 static meshes + LEDs + 2 screens + 2 rims + bulb = 26 draw calls (tested at <= 30; it was ~20 before the detail pass, the extra ones are the no-shadow buckets for small parts). About 40k triangles (tested < 80k). Furniture casts and receives shadows; the lamp shade, LEDs, keycaps, springs and small trinkets don't cast.

Simplifications: the chair is static (doesn't swivel); the side monitor is a static canvas.
