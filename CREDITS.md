# Credits

## Assets
All 3D geometry is built procedurally from primitives in code. All textures (wood, cork, fabric, paper, chalkboard, polaroid photos, the dusk sky, the terminal screen) are generated on a canvas at runtime or are SVG files generated by `seed/generate-photos.ts`. All sound is synthesized live with the Web Audio API.

The logo, icons and social preview image in `brand/` and `public/` were drawn as SVG for this project.

No third-party art, model, texture or audio files are shipped. Paid assets: $0.

## Sample data
The 12 sample escape rooms, companies, addresses and reviews in `seed/reviews.json` are fictional.

## Directory data
The venue directory in `seed/directory/` is derived from [Foursquare Open Source Places](https://opensource.foursquare.com/os-places/) (release 2025-02-06), licensed under Apache-2.0. Its `LICENSE.txt` and `NOTICE.txt` ship with the data, and `seed/directory/README.md` lists the changes we made. Public directory pages show this attribution. Venues and games added by users are their contributions.
